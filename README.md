# Автосервис 888 — статический сайт

Тёмная техно-стилистика с жёлтым акцентом и светлый вариант для светлой темы системы. Слайдер-баннеры (3 шт., автопрокрутка 6 с, пауза, свайп, стрелки), анимированные счётчики, косые переходы между блоками, баннер-полоса «каждый день 09–19», появление блоков слева и справа, полоса прогресса прокрутки, галерея с увеличением при наведении.

Данные взяты из 2ГИС (Excel): адрес, телефоны, часы работы, рейтинг, услуги из рубрик. Цены везде «по запросу».

## Как работает заявка
Клиент выбирает услуги, день и время, заполняет контакты и ставит согласие на обработку данных. Откроется **WhatsApp** сервиса с готовым текстом заявки, клиенту остаётся нажать «Отправить». Время не бронируется — его подтверждает администратор.

Telegram в данных 2ГИС не указан. Если он появится, впишите ссылку в `telegram` в файле `js/config.js` — в форме автоматически появится выбор WhatsApp или Telegram.

## Что где менять
- `js/config.js` — номер WhatsApp, Telegram, часы работы, на сколько дней вперёд открыта запись.
- `index.html` — тексты, услуги, контакты. Список услуг в форме строится сам из кнопок «Записаться».
- `privacy.html` — реквизиты оператора (выделенные поля).
- `js/booking.js` — общая логика формы, одинаковая для всех сайтов.

Все анимации отключаются, если в системе включено «Уменьшить движение».

## Размещение
Загрузите папку целиком на любой хостинг. Локально сайт можно открыть двойным щелчком по `index.html`.
